# KP VPN 0.2.0 preview

The app and website share a cyan/blue shield-and-network brand. Android keeps the existing native WireGuard backend and encrypted local profiles. SIM labels and filename hints organize profiles; they do not establish carrier compatibility or free mobile data.

The Android workflow builds, lints, runs native and UI tests, then publishes APK, SHA256SUMS and app-release.json to the immutable v0.2.0 preview release. Website download remains disabled until a valid manifest exists. Re-runs retain the existing published APK and its matching hash.

This preview uses a newly generated Android debug certificate. The previous app signing private key was not available. In-place upgrade from an old installation is not guaranteed; original configuration files should be retained before changing installations. No keystore or private VPN key is published.

Catalog jobs run every 30 minutes with scheduling delays possible. Eight deterministic roles are reported, with AI explicitly unconfigured. Daily educational lessons rotate without repetition until the curated bank is exhausted. Three read-only public website monitors run every 15 minutes and after successful publication. Reports cannot authorize arbitrary code changes.

AI model activation requires a separately authorized credential setup. No OpenAI request is made by the current pipeline.
