# KP VPN Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Automatically discover, verify and categorize eligible VPN files and teach users their actual compatibility.

**Architecture:** A finder produces bounded candidate metadata. An independent verifier fetches approved files, parses WireGuard, probes handshake/HTTPS in a namespace and emits a public catalog with credential-free metadata. The existing page consumes that catalog.

**Tech Stack:** Python 3.11 standard library, GitHub Actions, Linux wireguard-tools/iproute2/curl, static HTML/CSS/JS.

**Spec:** docs/superpowers/specs/2026-10-31-catalog-design.md

## Global Constraints
- No arbitrary credential scraping/publication; require registry redistribution approval.
- Cloud server verification never means SIM/nopro verified.
- Preserve existing daily-tip/chat/language behavior.
- No fabricated working configs; initialize approved sources empty.

## Review Focus
- Malformed configs/hooks/unknown protocol must fail before any network probe.
- URLs resolving to private addresses or unexpected hosts must fail.
- Failed/expired/revoked checks must remove downloads.
- A successful cloud probe must never promote an unrelated SIM report.
- Untrusted titles/URLs must remain inert in the page.

## Tasks
1. Write failing unittest cases for WireGuard parsing, deduplication, URL guards, exact-hash SIM evidence, failed-check withholding and publication cleanup. Run them, implement the core, run full suite.
2. Add finder and independent verifier entrypoints, a real isolated WireGuard probe and a bounded provenance registry. Exercise an empty-source dry run and discovery on CI.
3. Add catalog/guide sections and client filters to the existing page. Browser-check malicious titles, carrier/search behavior and responsive layout in CI; visually inspect generated screenshots.
4. Add scheduled two-job workflow and changed-only commits; review once, fix important findings, commit main and verify a real Actions run. Report real catalog counts and missing approved source/SIM data.
