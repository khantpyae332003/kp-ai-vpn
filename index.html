A LITTLE HELP

စသုံးဖို့ သိထားရမယ့်အချက်များ

01ဘယ်ဖိုင်တွေ သုံးလို့ရလဲ
WireGuard .conf[Interface] နဲ့ [Peer] ပါသော config
ZIP ဖိုင်အထဲမှာ WireGuard .conf ဖိုင်တွေ ပါရမည်
WireGuard QRConfig စာသားအပြည့် ပါသော QR

.ovpn၊ .ehi၊ .hc၊ .hat၊ VMess/VLESS/Trojan/Shadowsocks၊ JSON/YAML တို့ကို KP VPN v0.1 မှာ မချိတ်နိုင်သေးပါ။ ဖိုင်နာမည်ပြောင်းရုံနဲ့ format မပြောင်းပါ။

02ဖိုင် ဘယ်လိုရှာပြီး ထည့်မလဲ
  1. ယုံကြည်ရတဲ့ provider ရဲ့ official dashboard ထဲမှာ WireGuard configuration ကိုရှာပြီး .conf ကို ဖုန်းထဲသိမ်းပါ။
  2. KP VPN → ထည့်မယ် → ကိုယ့် SIM အမျိုးအစား ရွေးပါ။
  3. ဖိုင် / ZIP ကနေ ဖိုင်ရွေးပါ။ QR ရှိရင် QR ဖတ်မယ် ကိုနှိပ်ပါ။
  4. Config ရွေး → ပါဝါခလုတ်နှိပ် → Android VPN ခွင့်ပြုပြီး website တစ်ခု ဖွင့်စမ်းပါ။

ကိုယ့် account config ထဲမှာ private key ပါလို့ public မတင်ပါနဲ့။ Official config ရယူနည်း ↗

03SIM အလိုက် ဘယ်လိုပြင်မလဲ

App ထဲ SIM label ရွေးခြင်းနဲ့ dtac-nopro-….conf လို့ နာမည်ပေးခြင်းက စာရင်းခွဲဖို့သာ ဖြစ်သည်။ True ဖိုင်ကို dtac လို့ ပြောင်းခေါ်ရုံနဲ့ ချိတ်ဆက်မရလာပါ။

Provider က ကိုယ့် network အတွက် ထုတ်ပေးထားတဲ့ config ကို သုံးပါ။ PrivateKey / PublicKey / Endpoint / Address ကို ခန့်မှန်းပြီး မပြောင်းပါနဲ့။ Wi-Fi ပိတ်ပြီး SIM အစစ်နဲ့ စမ်းပါ။

nopro သည် source ရဲ့ label ဖြစ်ပြီး ဒေတာ package မရှိဘဲ သုံးရမည်ဟု အာမခံခြင်း မဟုတ်ပါ။

04“စစ်ပြီး” ဆိုတာ ဘယ်လောက်အထိလဲ

Server စစ်ပြီး: ဖိုင်ပုံစံမှန်ပြီး cloud မှ WireGuard handshake + HTTPS စမ်းသပ်မှု အောင်ထားခြင်း။ SIM အစစ်နဲ့ စစ်ခြင်း မဟုတ်ပါ။

SIM စမ်းသုံးသူတင်ပြ: Config hash တူပြီး ၂၄ နာရီအတွင်း cellular စမ်းသုံးသူ တင်ပြထားခြင်း။ အော်ပရေတာရဲ့ အတည်ပြုချက် မဟုတ်ပါ။

ဖိုင်များကို အများဆုံး ၂၄ နာရီသာ စာရင်းပြမည်။ မအောင်သောဖိုင်နဲ့ သက်တမ်းကုန်ဖိုင်ကို နောက် update မှာ ဖယ်မည်။ နေ့/ညမရွေး မိနစ် ၃၀ တစ်ခါ workflow စတင်ရန် သတ်မှတ်ထားသည်။ GitHub Actions သည် တစ်ခါ run ပြီးတစ်ခါ နားသောပုံစံဖြစ်ပြီး စတင်ချိန် နှောင့်နှေးနိုင်သည်။

05ချိတ်မရရင် ဘယ်လိုဖြေရှင်းမလဲ

၁။ ဖိုင်ထည့်လို့ မရဘူး

ဖုန်းရဲ့ Downloads ထဲက ဖိုင်ကို ရွေးပါ။ KP VPN v0.1 အတွက် WireGuard .conf သို့မဟုတ် ၎င်းဖိုင်ပါသော ZIP ဖြစ်ရမည်။ .ovpn / .ehi ကို နာမည်ပြောင်းရုံနဲ့ သုံးမရပါ။ ကိုယ့် provider ဆီက WireGuard config ပြန်ယူပါ။

၂။ ZIP ထဲမှာ ဖိုင်တွေ အများကြီးပဲ

ဖိုင်ကတ်ပေါ်က ဖိုင်နာမည် ကူးမယ် ကိုနှိပ်ပါ။ ဖုန်းရဲ့ Files app မှာ မူရင်း ZIP ကို ဖြည်ပြီး ကတ်ပေါ်ရေးထားသော ဖိုင်နာမည်အတိအကျကို ရှာပါ။ အဲဒီ .conf တစ်ဖိုင်ကိုသာ အရင်ထည့်စမ်းပါ။ တခြားဖိုင်အားလုံး အလုပ်လုပ်မည်ဟု မဆိုလိုပါ။

၃။ VPN စဖွင့်လို့ မရဘူး

တခြား VPN app ချိတ်ထားရင် ပိတ်ပါ။ KP VPN မှာ ဖိုင်ရွေးပြီး စချိတ်ပါ။ Android ရဲ့ VPN ခွင့်ပြုချက်တောင်းလာရင် အတည်ပြုပါ။ ခွင့်ပြုချက်မပေါ်လျှင် Android Settings ထဲက VPN ဆက်တင်နဲ့ တခြား VPN ရဲ့ Always-on / Block connections ဆက်တင်ကို စစ်ပါ။

၄။ VPN ချိတ်ပြီး website မဖွင့်နိုင်ဘူး

  1. VPN ကို ခဏပိတ်ပြီး ပုံမှန်အင်တာနက် ရမရ စမ်းပါ။ SIM ဒေတာနဲ့ package လက်ကျန်ကို စစ်ပါ။
  2. ပုံမှန်အင်တာနက် ရပေမယ့် VPN နဲ့ မရရင် စစ်ချိန်အသစ်ဆုံး တခြားဖိုင်ကို စမ်းပါ။ Public server က ပြည့်နေခြင်း၊ key ပိတ်သွားခြင်း သို့မဟုတ် network က UDP ကို ကန့်သတ်ခြင်း ဖြစ်နိုင်သည်။
  3. Provider ထုတ်ပေးထားတဲ့ config ကို အစစ်အတိုင်း ပြန်ထည့်ပါ။ PrivateKey / PublicKey / Endpoint ကို ခန့်မှန်းမပြင်ပါနဲ့။ ကိုယ့် server ဖြစ်လျှင် အောက်က server လမ်းညွှန်အတိုင်း key၊ firewall နဲ့ NAT ကို စစ်ပါ။

၅။ SIM နဲ့ စမ်းမယ် / အကူအညီတောင်းမယ်

Wi-Fi ပိတ်ပြီး mobile data နဲ့ စမ်းပါ။ အချိန်၊ SIM နာမည်၊ ဖိုင်နာမည်နဲ့ ပေါ်လာတဲ့ error စာသားကို မှတ်ထားပါ။ PrivateKey၊ PresharedKey၊ config အပြည့်နဲ့ QR ကို public မတင်ပါနဲ့။ Server စစ်ပြီးဆိုတာ SIM / nopro စမ်းပြီးလို့ မဆိုလိုပါ။

ကိုယ်ပိုင်ဖိုင် ပြုလုပ်မယ်

05ဖိုင်ပြုလုပ်ရန်နှင့် အသေးစိတ်လမ်းညွှန်

အလုပ်လုပ်တဲ့ VPN server သို့မဟုတ် ကိုယ်ပိုင် provider အကောင့် လိုအပ်သည်။ အောက်က builder က ကိုယ်ပိုင် WireGuard server ရှိသူ အတွက် client ဖိုင်လုပ်ပေးသည်။ Key ကို ဖုန်း browser ထဲမှာပဲ ထုတ်ပြီး server ဆီ မပို့ပါ။

နည်းလမ်း A — Server မရှိသူ၊ ဖုန်းတစ်လုံးနဲ့ အလွယ်ဆုံး
  1. ယုံကြည်ရတဲ့ VPN provider ရဲ့ official website မှာ ကိုယ့်အကောင့်နဲ့ ဝင်ပါ။
  2. Downloads → WireGuard configuration ထဲမှာ platform / server ရွေးပြီး config ထုတ်ပါ။ ဥပမာ Proton ရဲ့ official လမ်းညွှန်။
  3. ကိုယ့်အကောင့်အတွက် ထုတ်ပေးထားသော .conf ကို ဒေါင်းလုဒ်လုပ်ပါ။ Provider ထုတ်ပေးတဲ့ key တွေကို ဒီ builder က key အသစ်နဲ့ အစားမထိုးပါနဲ့။
  4. KP VPN → ထည့်မယ် → SIM label ရွေး → ဖိုင်ရွေးပြီး ထည့်ပါ။ PrivateKey ပါသော ကိုယ့်ဖိုင်ကို public မတင်ပါနဲ့။

နည်းလမ်း B — ကိုယ့် server အတွက် client ဖိုင်

ပထမ key ထုတ်ပါ။ Client PublicKey ကို server မှာ မှတ်ပုံတင်ပြီး server ရဲ့ အချက်အလက်အစစ်တွေ ဖြည့်ပါ။

PrivateKey ကို ဖိုင်ဒေါင်းလုဒ်ထဲမှာပဲ ထည့်ပေးမည်။

ဤနေရာမှ ပြုလုပ်သောဖိုင်သည် server စစ်ပြီးဖိုင် မဟုတ်သေးပါ။

ကိုယ်ပိုင် Ubuntu server ဘက်မှာ ဘာလုပ်ရမလဲ — အဆင့်လိုက်

ဤဥပမာမှာ မိမိပိုင် Ubuntu VPS / public IPv4 server၊ SSH အုပ်ချုပ်ခွင့်၊ UDP 51820 ဖွင့်ခွင့် လိုအပ်သည်။ ဖုန်းက SSH app သို့မဟုတ် provider ရဲ့ browser console နဲ့ ဝင်လုပ်နိုင်သည်။

၁။ WireGuard ထည့်ပြီး server key ထုတ်ပါ

sudo apt update
sudo apt install wireguard iptables
sudo install -d -m 700 /etc/wireguard
sudo sh -c 'umask 077; wg genkey > /etc/wireguard/server.key; wg pubkey < /etc/wireguard/server.key > /etc/wireguard/server.pub'
sudo cat /etc/wireguard/server.pub

နောက်ဆုံးပေါ်လာတဲ့ server public key ကို အပေါ် form ရဲ့ Server PublicKey ထဲ ထည့်ပါ။ server.key သည် private key ဖြစ်လို့ server ထဲမှာပဲ ထားပါ။

၂။ Server ရဲ့ internet interface နာမည် ကြည့်ပါ

ip -4 route show default

dev နောက်က eth0 / ens3 စသောနာမည်ကို ယူပါ။ Server template ယူပါ။ ဤဖိုင်သည် သင်ယူရန် placeholder ပါသော server ဥပမာဖြစ်ပြီး KP VPN ထဲ ထည့်သုံးရန် မဟုတ်ပါ။

၃။ /etc/wireguard/wg0.conf ပြုလုပ်ပါ

sudo nano /etc/wireguard/wg0.conf

Template ထဲ SERVER_PRIVATE_KEY ကို server ပေါ်ရှိ /etc/wireguard/server.key နဲ့ ဖြည့်ပါ။ ဒီ key ကို server ပေါ်မှာ sudo nano /etc/wireguard/server.key နဲ့သာ ဖွင့်ဖတ်ပြီး ကူးပါ။ Website ထဲ မထည့်ပါနဲ့။ CLIENT_PUBLIC_KEY ကို အပေါ်က builder ထုတ်ပေးသော public key နဲ့ ဖြည့်ပါ။ WAN_INTERFACE ကို အဆင့် ၂ က နာမည်နဲ့ အစားထိုးပါ။ Client ရဲ့ AllowedIPs = 10.8.0.2/32 နဲ့ form ထဲ client address တူရမည်။ ဖုန်းတစ်လုံးစီအတွက် သီးခြား key နဲ့ IP သုံးပါ။

၄။ IPv4 forwarding နဲ့ firewall ကို ပြင်ပါ

echo 'net.ipv4.ip_forward=1' | sudo tee /etc/sysctl.d/99-kp-wireguard.conf
sudo sysctl --system
sudo chmod 600 /etc/wireguard/wg0.conf

Cloud firewall မှာ UDP 51820 inbound ကို ဖွင့်ပါ။ UFW သုံးလျှင် sudo ufw allow 51820/udp နဲ့ ကိုယ့် WAN interface အတွက် sudo ufw route allow in on wg0 out on eth0 ကို ပြင်သုံးပါ။ SSH ဝင်ခွင့်ကို ဆက်ထားပြီး လက်ရှိ firewall policy နဲ့ ကိုက်ညီအောင် စစ်ပါ။ Template က IPv4 NAT လုပ်ပေးသည်။

၅။ Server စတင်ပြီး ဖုန်းဖိုင်ကို ထည့်ပါ

sudo systemctl enable --now wg-quick@wg0
sudo wg show wg0

အပေါ် form ထဲ Endpoint ကို ကိုယ့် server public IPv4:51820 နဲ့ဖြည့်ပါ။ ကိုယ်ပိုင်ဖိုင်ယူပြီး KP VPN ထဲ import လုပ်ပါ။ ဖုန်းက စချိတ်ပြီးနောက် latest handshake နဲ့ transfer bytes တက်မတက်၊ website ဖွင့်လို့ရမရ စမ်းပါ။ ဒီ IPv4 ဥပမာမှာ IPv6 ကိုလည်း tunnel ထဲ ညွှန်ထားသဖြင့် server က IPv6 မပံ့ပိုးလျှင် IPv6 ချိတ်ဆက်မှု မရနိုင်ပါ။

မရလျှင် key နှစ်ဖက် ကိုက်ညီမှု၊ client IP၊ server Endpoint/port၊ UDP firewall၊ forwarding/NAT ကို အစဉ်လိုက်စစ်ပါ။ SIM နာမည်ပြောင်းခြင်းက ဒီပြဿနာတွေကို မဖြေရှင်းပါ။ Official WireGuard လမ်းညွှန် ↗
