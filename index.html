SIM အလိုက် VPN ဖိုင်စာရင်း

ရှာဖွေပြီး စစ်ဆေးမှုအောင်တဲ့ WireGuard ဖိုင်တွေကို SIM နာမည်အလိုက် စုစည်းပေးမည်။ မိနစ် ၃၀ တစ်ခါ workflow စတင်ရန် သတ်မှတ်ထားသည်။

① ရှာဖွေသော Agent

Public source link တွေ ရှာပြီး မျှဝေခွင့်ရှိကြောင်း သတ်မှတ်ထားတဲ့ feed မှ ဖိုင်စာရင်းယူသည်။

② စစ်ဆေးသော Agent

ဖိုင်ပုံစံ၊ key နဲ့ route ကိုစစ်ပြီး WireGuard handshake + HTTPS စမ်းသပ်အောင်မှ download စာရင်းတင်သည်။

nopro သည် မူရင်းရင်းမြစ်၏ အမျိုးအစားအမည်ဖြစ်သည်။ Cloud server စမ်းသပ်မှုက SIM တစ်ခုချင်းမှာ ဒေတာ package မရှိဘဲ သုံးနိုင်ကြောင်း မသက်သေပြပါ။ SIM စမ်းသပ်မှုကို သီးခြားဖော်ပြမည်။

၁။ KP VPN နဲ့ရတဲ့ဖိုင် ဘယ်လိုရှာမလဲ
  1. ယုံကြည်ရတဲ့ VPN provider ရဲ့ official account / dashboard ထဲမှာ WireGuard configuration သို့မဟုတ် Download .conf ကိုရှာပါ။
  2. Official guide ကနေ server နဲ့ key ထုတ်ပြီး config ကို ဖုန်းထဲ ဒေါင်းလုဒ်လုပ်ပါ။ Config ထဲမှာ private key ပါလို့ ကိုယ့် account ဖိုင်ကို public site မတင်ပါနဲ့။
  3. အများပြည်သူမျှဝေဖို့ ထုတ်ပေးထားသော feed ဖြစ်မှ Website ရဲ့ source registry ထဲ ထည့်ပါ။ ရှာတွေ့တဲ့ GitHub link တိုင်းဟာ ယုံကြည်ရတဲ့ provider မဟုတ်ပါ။
  4. ဒီ website မှာဆို Server စစ်ပြီး အခြေအနေနဲ့ စစ်ချိန်၊ သက်တမ်းကိုကြည့်ပါ။ SIM အခြေအနေကို သီးခြားစစ်ပါ။

Official guide: WireGuard config ဒေါင်းလုဒ်နည်း · WireGuard အခြေခံ။ Account/အစီအစဉ်ပေါ်မူတည်ပြီး လိုအပ်ချက် ကွာနိုင်သည်။

၂။ ဖုန်းကနေ KP VPN ထဲ ဘယ်လိုထည့်မလဲ
  1. အလုပ်လုပ်တဲ့ WireGuard .conf ဖိုင်ကို ဖုန်းထဲသိမ်းပါ။
  2. KP VPN → ထည့်မယ် → SIM အမျိုးအစား ရွေးပါ။
  3. ဖိုင် / ZIP ကိုနှိပ်ပြီး ဖိုင်ရွေးပါ။ QR ရှိလျှင် QR ဖတ်မယ် ကိုနှိပ်ပါ။
  4. စာရင်းထဲက config ရွေး → ပါဝါခလုတ်နှိပ် → Android VPN ခွင့်ပြုပါ။
  5. Website တစ်ခု ဖွင့်စမ်းပြီး traffic လက်ခံမှုကို ကြည့်ပါ။ Tunnel ဖွင့်ထားရုံနဲ့ server အလုပ်လုပ်တယ်လို့ မယူဆပါနဲ့။
၃။ SIM နာမည်အလိုက် ဘယ်လိုပြန်ခွဲမလဲ

dtac-nopro-<hash>.conf လို ဖိုင်နာမည်နဲ့ app ထဲ SIM label သတ်မှတ်ခြင်းက စာရင်းစီခြင်းသာ ဖြစ်သည်။ True config ကို dtac လို့ rename လုပ်ရုံနဲ့ dtac မှာ အလုပ်မလုပ်လာပါ။

  1. ကိုယ်သုံးတဲ့ SIM အစစ်၊ လက်ရှိ network နဲ့ data plan ကို အရင်ကြည့်ပါ။
  2. Provider က အဲဒီ network အတွက် သတ်မှတ်ပေးထားတဲ့ server/port/config ရှိရင် အဲဒါကိုယူပါ။
  3. PrivateKey / PublicKey / Endpoint / Address ကို ခန့်မှန်းပြီး မပြောင်းပါနဲ့။ Server ဘက်မှာ ကိုက်ညီအောင် ပြင်ဆင်ထားဖို့ လိုအပ်သည်။
  4. App ထဲထည့်ချိန် မှန်တဲ့ SIM label ရွေးပြီး Wi-Fi ပိတ်ကာ မိမိ SIM နဲ့ စမ်းပါ။

SIM နာမည်က data package၊ APN သို့မဟုတ် server authentication ကို အစားမထိုးပါ။

၄။ “စစ်ပြီး” ဆိုတာ ဘယ်လောက်အထိလဲ
  • ဖိုင်ပုံစံစစ်ခြင်း: WireGuard field/key/route မှန်မမှန်။ ဒါတစ်ခုတည်းနဲ့ download စာရင်းမတင်ပါ။
  • Server စစ်ခြင်း: Cloud မှ fresh handshake နဲ့ HTTPS route စမ်းသပ်အောင်ခြင်း။ SIM အစစ်နဲ့ စမ်းခြင်း မဟုတ်ပါ။
  • SIM အစီရင်ခံစာ: Config hash တူပြီး ၂၄ နာရီအတွင်း cellular စမ်းသုံးသူ တင်ပြထားခြင်း။ သက်သေ link ပါမည်။ အော်ပရေတာအတည်ပြုချက် မဟုတ်ပါ။
  • သက်တမ်း: စစ်ချိန်ကနေ အများဆုံး ၂၄ နာရီသာ စာရင်းပြမည်။ မအောင်၊ သက်တမ်းကုန်လျှင် နောက် run မှာ download ဖိုင်ဖယ်မည်။

သိထားသင့်တာတွေ

Public Wi‑Fi

မသိတဲ့ Wi‑Fi မှာ banking၊ email လို အရေးကြီးတာတွေ မဖွင့်ပါနဲ့။ HTTPS ပါတဲ့ site ပဲ သုံးပါ။

2FA ဖွင့်ပါ

Password တစ်ခုတည်းမကပါဘဲ 2-step verification ဖွင့်ထားရင် account ပိုလုံခြုံပါတယ်။

အခမဲ့ config ကို သတိထားပါ

ပိုင်ရှင်မသိတဲ့ အခမဲ့ VPN config တွေက သင့် traffic ကို ကြားဖြတ်ကြည့်နိုင်ပါတယ်။ ယုံကြည်ရတဲ့ provider ကိုပဲ သုံးပါ။

မေးလေ့ရှိတဲ့ မေးခွန်း

VPN ဆိုတာ ဘာလဲ

VPN က သင့်အင်တာနက် ချိတ်ဆက်မှုကို encrypt လုပ်ပြီး server တစ်ခုကတဆင့် လွှင့်ပေးတဲ့ tool ပါ။ Public Wi‑Fi မှာ အသုံးဝင်ပါတယ်။ ဒါပေမယ့် 100% anonymous မဟုတ်ပါဘူး။

အခမဲ့ VPN ဘာကြောင့် အန္တရာယ်ရှိနိုင်သလဲ

ပိုင်ရှင်ကို မသိရင် traffic ကို ကြည့်နိုင်၊ ဒေတာ ရောင်းနိုင်ပါတယ်။ Open source ဖြစ်ပြီး privacy policy ရှင်းတဲ့ provider ကို ရွေးပါ။

ဖိုင်စာရင်း ဘယ်လို update လုပ်သလဲ

ရှာဖွေသော agent နဲ့ စစ်ဆေးသော agent က မိနစ် ၃၀ တစ်ခါ စတင်ပြီး မျှဝေခွင့်ရှိသောဖိုင်ကို server စမ်းသပ်အောင်မှ စာရင်းတင်မည်။ GitHub schedule သည် နှောင့်နှေးနိုင်သည်။

Config catalog ကို အပေါ်မှာကြည့်ပါ။ စစ်ပြီးဖိုင်မရှိလျှင် မရှိကြောင်းပြမည်။ ကိုယ်ပိုင် account config နဲ့ private key ကို public မတင်ပါနဲ့။
