A LITTLE HELP

စသုံးဖို့ သိထားရမယ့်အချက်များ

01ဘယ်ဖိုင်တွေ သုံးလို့ရလဲ
WireGuard .conf[Interface] နဲ့ [Peer] ပါသော config
ZIP ဖိုင်အထဲမှာ WireGuard .conf ဖိုင်တွေ ပါရမည်
WireGuard QRConfig စာသားအပြည့် ပါသော QR

.ovpn၊ .ehi၊ .hc၊ .hat၊ VMess/VLESS/Trojan/Shadowsocks၊ JSON/YAML တို့ကို KP VPN v0.1 မှာ မချိတ်နိုင်သေးပါ။ ဖိုင်နာမည်ပြောင်းရုံနဲ့ format မပြောင်းပါ။

02ဖိုင် ဘယ်လိုရှာပြီး ထည့်မလဲ
  1. ယုံကြည်ရတဲ့ provider ရဲ့ official dashboard ထဲမှာ WireGuard configuration ကိုရှာပြီး .conf ကို ဖုန်းထဲသိမ်းပါ။
  2. KP VPN → ထည့်မယ် → ကိုယ့် SIM အမျိုးအစား ရွေးပါ။
  3. ဖိုင် / ZIP ကနေ ဖိုင်ရွေးပါ။ QR ရှိရင် QR ဖတ်မယ် ကိုနှိပ်ပါ။
  4. Config ရွေး → ပါဝါခလုတ်နှိပ် → Android VPN ခွင့်ပြုပြီး website တစ်ခု ဖွင့်စမ်းပါ။

ကိုယ့် account config ထဲမှာ private key ပါလို့ public မတင်ပါနဲ့။ Official config ရယူနည်း ↗

03SIM အလိုက် ဘယ်လိုပြင်မလဲ

App ထဲ SIM label ရွေးခြင်းနဲ့ dtac-nopro-….conf လို့ နာမည်ပေးခြင်းက စာရင်းခွဲဖို့သာ ဖြစ်သည်။ True ဖိုင်ကို dtac လို့ ပြောင်းခေါ်ရုံနဲ့ ချိတ်ဆက်မရလာပါ။

Provider က ကိုယ့် network အတွက် ထုတ်ပေးထားတဲ့ config ကို သုံးပါ။ PrivateKey / PublicKey / Endpoint / Address ကို ခန့်မှန်းပြီး မပြောင်းပါနဲ့။ Wi-Fi ပိတ်ပြီး SIM အစစ်နဲ့ စမ်းပါ။

nopro သည် source ရဲ့ label ဖြစ်ပြီး ဒေတာ package မရှိဘဲ သုံးရမည်ဟု အာမခံခြင်း မဟုတ်ပါ။

04“စစ်ပြီး” ဆိုတာ ဘယ်လောက်အထိလဲ

Server စစ်ပြီး: ဖိုင်ပုံစံမှန်ပြီး cloud မှ WireGuard handshake + HTTPS စမ်းသပ်မှု အောင်ထားခြင်း။ SIM အစစ်နဲ့ စစ်ခြင်း မဟုတ်ပါ။

SIM စမ်းသုံးသူတင်ပြ: Config hash တူပြီး ၂၄ နာရီအတွင်း cellular စမ်းသုံးသူ တင်ပြထားခြင်း။ အော်ပရေတာရဲ့ အတည်ပြုချက် မဟုတ်ပါ။

ဖိုင်များကို အများဆုံး ၂၄ နာရီသာ စာရင်းပြမည်။ မအောင်သောဖိုင်နဲ့ သက်တမ်းကုန်ဖိုင်ကို နောက် update မှာ ဖယ်မည်။ Workflow စတင်ချိန်သည် နှောင့်နှေးနိုင်သည်။

ရှာတွေ့ရင်းမြစ်များအတည်မပြုရသေး

ဒီ link တွေက ရှာဖွေမှုရလဒ်များသာ ဖြစ်သည်။ KP VPN နဲ့ရမည့် download ဖိုင်ဟု မသတ်မှတ်ရသေးပါ။
